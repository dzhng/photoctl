# Planning drafts

The blind build-plan drafts written at the spec's kickoff (Claude A, B and D;
Codex C) and the notes that synthesized them into the ladder the closed
[v1 record](../../README.md) describes. They are kept verbatim as provenance
for how the plan was chosen, not as live documentation: they name slice
numbers, file paths and line numbers as they stood on 2026-09-03, and the
Codex draft cites precedent code in sibling repositories by absolute path on
the author's machine. None of these references is maintained; do not repoint
them, and do not treat them as claims about the shipped code.
