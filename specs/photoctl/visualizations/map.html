Sharp edges — awareness, one right answer

  • edge Timezone: parse DateTimeOriginal + OffsetTimeOriginal; store instant + offset; {date} uses the shot's local date; never the machine's zone. exifr shifted the sample 6 h.
  • edge Gemini box_2d is [ymin,xmin,ymax,xmax] normalized 0–1000, origin top-left; Apple Vision normalized coords are origin lower-left. Adapter converts; never leak.
  • edge LibRaw dcraw_process() defaults: 8-bit, BT.709 gamma labeled sRGB, auto-bright ON clipping 1 %, use_camera_wb=0. Use LibRaw for unpack + metadata + demosaic only; write the pipeline (black/white levels, WB, cam_xyz, tone, sRGB piecewise TRC with negative reflection, embed sRGB2014.icc).
  • edge LibRaw and rawler disagree on white level (16383 vs 15360) → highlight clipping differs; the two-decoder oracle must tolerate it.
  • edge Build LibRaw --disable-openmp or the .node embeds an /opt/homebrew libomp path. Keep libc++ dynamic. Ship darwin-arm64 and darwin-x64 as separate napi packages.
  • edge CIRAWFilter validity: non-nil for junk; check supportedDecoderVersions != ["None"]; identifierHint required; software renderer is a no-op on Apple Silicon; SSH/no-window-server untested.
  • edge Sony M/S lossless is YCbCr pseudo-RAW with WB already applied (as_shot_wb_applied) — don't apply WB twice.
  • edge Unix socket path ≤ 104 bytes on macOS (131 chars → EINVAL). Socket in $TMPDIR, never in the library.
  • edge Photos' "Vibrance" is not CIVibrance (it's SmartColor.offsetContrast); Brilliance = SmartTone.offsetLocalLight with a 31×31 lightMap — replicate the architecture, not the curve.
  • edge AgX has no license file; ACES is a custom AMPAS license despite GitHub's badge; Adobe .dcp files may not be bundled; RawTherapee's public-domain DCPs cover no Sony body.
  • edge Free-tier embedding models may retain requests for training — never for a private library.
  • edge GPL-3 weights (e.g. darktable's Bayer denoiser): don't bundle in a permissive distributable; fine for personal use; fine as opt-in download with license shown. The CDDL wall applies to linked code only.
  • edge PGlite fsync=off by default, parallelism hard-disabled, ~2.5× disk amplification, 4 GB wasm32 ceiling untested above 673 MB.
  • edge Embedding worker + poll backoff pairing is admitted unsound in duet (embedding-worker.ts:52–58); re-derive yield vs ceiling together.

Integration test cases (functional, through the CLI)

  • Gold exam, keyless: import --link → list → rate 10 → develop 3 --preset people → export JPEGs; no gateway key present; human accepts output.
  • Person-move flow: segment --text → --move --by → vacancy → fill --remove strict → fill --prompt expand=200 → Tier-1 nudge (layers follow) → Tier-2 change (stale) → export writes with warnings.
  • Concurrency race: N real processes × M inserts on one library → exactly N×M rows; over-capacity → loud library_locked/refusal, never silent loss (seed: spike/).
  • Re-import idempotency: import twice → already_present = all; move a file on the volume → same id, new locator.
  • Offline drive: unmount → list shows online:false, develop works, export exits 69, previews serve from cache.
  • Timezone: a7c2.ARW imports as 2023-10-02 local, +02:00; {date} renders 2023-10-02 regardless of machine zone.
  • Strict composite: for any model adapter, every pixel outside the mask equals the pre-fill render bit-for-bit.
  • Decoder oracle: CIRAWFilter vs LibRaw render of a7c2.ARW agree within a stated tolerance after both pipelines' WB and TRC.
