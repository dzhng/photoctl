# Spec: photoctl (David's input spec, 2026-09-03, verbatim + delta)

CLI-first photo library + editor for Mac (portable core). Personal tool first; designed to OSS later. Hand this file to a coding agent. Do not invent product scope beyond this doc.
Status: READY FOR IMPLEMENTER. First user: David (Sony A7C II, ARW). Agents (Grok Bot / Cursor) must drive 100% via CLI. Binary name: photoctl.

One-line product: Import photos into a library, organize/rate/search, develop (Apple Photos–level + generative edits), markup, export — all from a CLI an agent can run. GUI later is a client of the same verbs, never a super-set.

Coding-agent prompt: Build photoctl from this spec. TypeScript/Node CLI + PGlite library + Rust native addon for LibRaw/mask/composite hot path. Mac first. Agent gold exam: import A7C II ARWs → rate → develop preset → export JPEGs with no GUI. Do not call AUTOMATIC1111/Comfy at runtime — reimplement inpaint ideas. Do not build a GUI in v1. Follow implementation order. Ask David only for: ARW folder path, Classic XMP export confirmation, and which generate/fill provider credentials to use.

Non-goals (v1): GUI; calling A1111/Forge/Comfy/darktable/digiKam as a subprocess; Lightroom Classic depth (Camera Matching, local HSL); Best Take / Add Me; Live Photo, Portrait-mode fakes, red-eye; cloud sync, mobile, books, maps, multi-user server; Adobe develop-history migration (ratings/keywords/XMP only).

Architecture: agent/human → photoctl CLI (+ MCP later = same verbs) → PGlite library (canonical) → XMP read/write (portability) → preview cache → develop + generative providers → Rust img hot path (LibRaw, masks, composite, export) → files on disk (--link or --copy). CLI completeness rule: anything a future UI can do, the CLI can do first.
Stack: TypeScript/Node: CLI, PGlite, embeddings/search, provider orchestration (same family as dzhng/duet-agent). Rust native addon or photoctl-img binary: LibRaw decode, preview pyramid, mask dilate/blur, pixel overlay, encode. Generative providers: pluggable.

Library: PGlite canonical (id, path, rating, tags, exif, develop, layers, markup, export history, embeddings). tsvector full-text on tags/filename/caption/folder. pgvector embeddings; hybrid search = vector cosine + tsvector fused with RRF (steal retrieval shape from duet-agent; no runtime dependency). Embed in a background worker after import. Store embedding model id per row. XMP: read on import (Classic stars/keywords); PGlite wins on conflict after first import; embeddings never in XMP. Preview cache under library path; deletable. Default import --link; --copy optional.

CLI contract: Stable JSON on stdout for agents. --human for tables. IDs are library UUIDs, not paths. Mutating commands must be safely retryable. Never overwrite RAW bytes.
Verbs: init [--path]; import <folder> [--copy|--link] [--recursive]; list [--rating N] [--tag T] [--folder F]; search <query>; show <id|path> (includes width/height); rate <id...> --stars 0..5; tag <id...> --add|--remove; develop <id...> --preset <name> | --set key=value...; presets list|show|save; filter <id> --name <apple-filter> --strength 0..1; crop <id> --aspect [--straighten deg] [--auto]; retouch <id> --at x,y [--radius n]; segment <id> --at x,y [--box x,y,w,h] [--brush '[[x,y],...]']; layer list <id>; fill <id> --layer L --remove | --prompt "..." [--ref path] [--fit strict|expand[=N]|free] | --move --to x,y [--scale n] | --outpaint [--aspect] [--px N]; fill ... [--full-res] [--pad N] [--strength f] [--init original|fill|noise|empty]; reimagine <id> --prompt [--strength f] (FULL IMAGE; may drift); relight <id> --azimuth --elevation --intensity; markup list|add|update|remove|clear <id> ...; generate --prompt [--model] [--size WxH] [--seed] [--neg] | --ref <path> [--strength]; export <id...> --to <dir> --format jpeg|tiff|png [--quality N]; doctor.
Coords: image pixels, origin top-left; --norm optional (0..1).

Develop (Apple Photos bar): Light: brilliance, exposure, highlights, shadows, brightness, contrast, black_point. Color: saturation, vibrance, cast. B&W: intensity, neutrals, tone, grain. Also white_balance (temp/tint or eyedropper), curves, levels, definition, selective_color, noise_reduction, sharpen, vignette; auto_enhance; copy_edits_from. Filters: vivid, vivid_warm, vivid_cool, dramatic, dramatic_warm, dramatic_cool, mono, silvertone, noir + strength. Crop: crop, rotate, straighten, aspect_ratio, auto_straighten. Retouch: non-generative heal brush. Ship 3 presets: neutral, people, high-contrast.

Generative: one fill pipeline; --remove = Clean Up/Magic Eraser mode. fill --fit strict (hard mask; composite restores every unmasked pixel exactly) | expand[=N] (dilate N px, default 24) | free (soft mask). Implement --fit as: build diffusion mask → optional full-res crop → provider inpaint → overlay(original, gen, mask). Defaults: replace → expand=24; remove → strict. A1111 reference only: only-masked crop + --pad, mask blur/soft inpaint → free, denoising --strength, masked content --init, shared provider surface. Layers: real rows in PGlite; JPEG export flattens.
Markup: vector overlay JSON in PGlite; primitives text, arrow, line, rect, ellipse, path, highlight; flatten on JPEG export.
Generate (bonus): writes file and imports tagged generated.

Gold exam (must pass): on David's Mac, photoctl on PATH: import folder of A7C II ARWs from external drive (--link); list + rate 10; develop 3 with --preset people; export JPEGs; human accepts JPEGs as not broken. Fail if a GUI is required.
Implementation order: 1 init, schema, doctor. 2 import --link, embedded JPEG + EXIF, list/show/rate/tag, XMP read. 3 export JPEG from preview/identity path. 4 Rust LibRaw + preview pyramid. 5 develop --set/presets + XMP write. 6 background embed + search (RRF). 7 segment + layers + fill + composite. 8 reimagine, unblur, relight, markup, generate. 9 optional MCP.
Success criteria: gold exam with no Adobe and no GUI; PGlite canonical; XMP round-trips ratings/tags; search returns useful hybrid hits; fill --fit strict leaves unmasked pixels bit-exact; reimagine is clearly full-frame; core has no AppKit requirement, Mac-only code isolated; no runtime dependency on A1111/Comfy/darktable UI.
