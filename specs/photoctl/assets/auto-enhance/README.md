# Auto-enhance visual checkpoint

This deterministic synthetic scene isolates the visible consequence of one C4 develop batch. It is
an execution-path check, not a claim about photographic taste: the useful invariant is that the
current render changes tonally while its dimensions, framing, content, and edge structure remain
stable.

`before.png` is the current 1024-pixel preview and `after.png` is the same revision after the fake
structured provider's ordinary develop adjustments. `comparison.png` presents that pair in order;
`metrics.json` records the pixel and edge telemetry used to verify that the production path was not
a no-op.
